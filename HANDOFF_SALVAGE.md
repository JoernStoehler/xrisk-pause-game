# Session-work salvage and retirement

Status: handoff scratch record, 11 July 2026. Branches remain recoverable; this
file classifies their value so a fresh root does not treat every artifact as an
equal candidate or reread the session to rediscover its failures.

## Disposition vocabulary

- **Carry forward:** sufficiently useful and bounded to include in the curated
  handoff evidence branch.
- **Mixed quarry:** contains reusable mechanisms or reasoning, but also a
  rejected direction or unsupported conclusion. Inspect only for a named need.
- **Superseded:** later work preserves the useful part more clearly.
- **Abandoned:** do not build forward from the artifact. The branch remains as
  evidence and recovery history.

## Specific prototype salvage

If a future root wants the stronger causal kernel without the rejected product,
port only named model boundaries and their focused tests from `7cbf546` or
`7f23bc2` into a new branch. Do not merge either prototype wholesale.

Candidate model-level salvage:

- requested directive versus implementation outcome;
- full, narrowed, and blocked implementation receipts, visibly uncalibrated;
- DG-visible information projection versus sampled-world retrospective;
- branch-specific event derivation from one seeded world;
- law/deterrence remaining active when factual custody is added;
- typed opening-directive, operational-response, and navigation actions;
- tests forbidding hidden truth, fake corroboration, and accidental policy
  commitment.

Do not salvage without fresh design justification:

- the finite first-watch card sequence;
- all current visual tokens and portrait assets;
- dense dossier presentation;
- confirmation-before-every-action patterns;
- current player-facing prose;
- current art direction;
- a campaign or case laboratory as the selected product shape.
