# Literature directory guidance

These rules apply to changes under `literature/`. The corpus is a navigation and
research aid; inclusion, extraction, and project notes do not certify accuracy,
completeness, or current coverage.

- Preserve a source's identity and wording when retaining a conversion or
  excerpt. Label omissions, extraction or OCR limits, and project-written
  descriptions or commentary so readers can distinguish them from source text.
- Distinguish full-source conversions, bounded excerpts, multi-source
  compilations, project syntheses, and retrieval notes when the record supports
  that classification. If not checked, leave the classification unverified;
  do not infer evidence quality or add generic tags to fill gaps.
- Keep the corpus flat. Update `INDEX.md` and relevant README navigation when
  adding, removing, renaming, or materially reclassifying a resource. Use
  relative links and record a logical plaintext path separately from its
  tracked `.enc` path where needed.
- Describe availability precisely: a locally retained file, a tracked
  ciphertext, a source available at its cited URL, and a source not retrieved
  are different states. Retrieval failures are dated observations, not claims
  of permanent unavailability.
- Keep private plaintext and secret keys out of version control. Follow the
  existing decryption script and local key setup; do not copy secret material
  into this directory or rewrite ciphertext as if it were readable source.
