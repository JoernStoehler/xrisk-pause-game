# Jörn review packets

Ask a prioritized list of self-contained, single-issue questions without hidden
premises. Match answer type: probability for uncertain claims, labeled options
for decisions, and free text for information. Never encode processes,
classifications, preferences, or compound statements as true or false.

Define codes inline: `pNN` means NN percent, `idk` means no current view, and
`mu` means malformed; rewrite it without inference.
