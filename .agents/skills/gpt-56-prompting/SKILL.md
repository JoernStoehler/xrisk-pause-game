# GPT-5.6 prompting

Before working on an agent-facing instruction surface, fetch and read the current versions of:

- [GPT-5.6 prompt guidance](https://developers.openai.com/api/docs/guides/prompt-guidance-gpt-5p6)
- [Codex customization and AGENTS.md guidance](https://learn.chatgpt.com/docs/customization/overview#when-to-update-agentsmd)

Use the OpenAI documentation skill or official documentation connector when available. If current documentation cannot be retrieved, state that limitation instead of silently relying on memory.

When creating or changing a skill, also use the built-in skill-creator workflow and its validator.
