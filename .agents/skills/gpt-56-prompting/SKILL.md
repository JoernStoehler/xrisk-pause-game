# GPT-5.6 prompting

Before substantive work on an agent-facing instruction surface, fetch and read the current versions of:

- [GPT-5.6 prompt guidance](https://developers.openai.com/api/docs/guides/prompt-guidance-gpt-5p6)
- [Codex customization and AGENTS.md guidance](https://learn.chatgpt.com/docs/customization/overview#when-to-update-agentsmd)

Use the OpenAI documentation skill or official documentation connector when available. A fresh copy already loaded in the current session may be reused. If current documentation cannot be retrieved, state that limitation instead of silently relying on memory.
