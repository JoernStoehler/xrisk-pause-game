# Plan From Playtest Readiness

Use this reference before a costly human playtest, facilitator trial, expert
review, or Jörn product/domain review.

Begin with the actual participant, use context, decision, artifact, and evidence
the gate can produce. Read the relevant lanes in
`docs/review/REVIEW_ROUTING.md`. A successful gate is evidence only for the
participant, artifact, conditions, and questions it exercised.

Remove cheaper prerequisite failures in dependency order. Check domain and game
semantics before polishing a misleading interaction; check basic interaction,
responsive rendering, and accessibility before spending participant attention;
check that the protocol can discriminate the live alternatives before treating
completion or preference as evidence.

Rehearse the gate as faithfully as is economical. Use fresh agents for cold
orientation or structural critique where useful, but do not treat agents as
players. Pilot the hardest representative moment early and preserve enough time
and source context to redesign it if the artifact is not a useful starting
point.

State in advance what observations support, weaken, or fail to inform the
product hypothesis. Keep coaching, comprehension, enjoyment, continuation,
retelling, facilitator usability, and demand distinct when pooling them would
hide the decision. Record participant privacy and consent constraints when
applicable.

Put durable, decision-changing results in the narrowest product or review owner.
Preserve a past failure only when it corrects a prior that future work is likely
to repeat; Git history is enough for obsolete artifacts with no continuing use.
