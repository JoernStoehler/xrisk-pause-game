the previous session. They are draft synthesis, neither Jörn-approved content

## Check a claim or expand research

Use [interviews/jorn.md](../interviews/jorn.md) for preserved attributed records
and [literature navigation](../literature/README.md) for source retrieval. A
topic's source pointer should name a meaningful passage: section/page or heading,
optionally current line range. Line numbers help inspect a file but may drift;
preserve source identity and locator context. Source notes can be added when
they save repeated triage, without making a notes file mandatory for every item.

Some brief pointers use `git show 2552820:<path>` to a specific older synthesis.
They let you inspect a supporting decision without making the old hierarchy
active. The full baseline commit is
`255282028d6d5e13274bd21b80a00dbd7b902f44`; see the root [README](../README.md)
and [INSTALL](../INSTALL.md) for recovery. An archived agent claim remains an
agent claim; source completeness, quotations, current law, and comparative
probabilities may require independent checking.
