# Expert-model atlas

Freshness: the substantive synthesis was assembled and reviewed in July 2026
and has not been revalidated against later evidence or renewed Jörn judgment.
“Current” below means the latest recorded project synthesis, not a claim of
August 2026 factual currency or approval.

## Purpose

This atlas presents the project's current beliefs about an international pause on frontier AI: what may happen, why, what interventions change, and where the model is weak. It is optimized for knowledge transfer and expert criticism.

It is **not** the game engine, a specification for the engine, or a claim that the territory is naturally a tidy graph. The engine must eventually make every transition executable and numerically complete. The expert model is allowed to remain partly verbal, conditional, internally plural, and explicit about missing ontology.

The atlas should help a reviewer answer four different questions without reading the whole research archive:

1. What does the project currently believe?
2. What arguments and evidence produced that belief?
3. Which alternative models remain live?
4. Which disagreements would change policy or game behavior?

## What the atlas records

The basic unit is not a variable. It is a **claim with conditions**. A claim may describe a causal mechanism, a constraint, a forecast, an observation model, or a live alternative. Claims can point to dense submodels, equations, historical cases, or unresolved questions.

Likelihood is recorded only where useful. The default vocabulary is:

- **structurally expected:** generated by many live models, though its magnitude may be unknown;
- **central branch:** a reasonable default trajectory conditional on the stated setup;
- **live branch:** not the default, but too plausible or consequential to prune;
- **tail branch:** unlikely under the current model but decision-relevant;
- **unresolved:** the project lacks either an adequate ontology or enough evidence to rank the alternatives.

These are deliberately not disguised numeric intervals. A later calibrated forecast should state its reference class, horizon, conditioning assumptions, and elicitor separately.

## Separation from the game model

The two layers should be maintained independently.

| Expert-model atlas | Game-model reference |
|---|---|
| Preserves incompatible hypotheses | Must sample or approximate them |
| Can say that a causal ontology is inadequate | Must still produce an outcome |
| Can leave likelihoods partial or ordinal | Must complete the distributions for branches actually sampled in playable runs, while allowing unweighted stress scenarios outside that distribution |
| Records reasons, provenance, and disputes | Records executable state and transitions |
| Optimized for understanding and criticism | Optimized for play, speed, and pedagogical value |

An engine feature may cite an atlas claim, but atlas claims should not silently inherit assumptions from the code. A future comparison artifact can state where the engine compresses, omits, or deliberately distorts this atlas.

## Editorial rules

1. State the conditioning world before the forecast.
2. Separate latent events from observations of those events.
3. Separate an actor's belief, stated belief, preference, authority, and conduct.
4. Treat historical analogies as sources of mechanisms and warning signs, not direct base rates for an ASI treaty.
5. State when a source supports only a component of a synthesis.
6. Preserve rival hypotheses when current evidence does not select among them.
7. Do not add numerical precision merely because the engine will eventually require it.
8. Mark a claim as high-cost when representing it faithfully would consume substantial game complexity for little expected discourse value.
