# Autonomous model-presentation workplan

## Current objective

Produce a reviewable high-level view of forecasting under an international AI
pause, including which detail is worth representing in the game. Return to Jörn
only when the artifacts support productive discussion of structural cruxes,
first-year likelihoods, and pruning choices.

## Deliverable group A — expert model

- top-level territory map;
- current conclusions and causal arguments;
- technical, institutional, political, and safety hypothesis families;
- evidence/provenance and source-priority rules;
- conditional forecasts and weak correlations;
- known unknowns, disagreement register, and deliberately implicit areas;
- first-year forecast hooks without fake completion of a joint prior.

Acceptance test: an expert can state what the project believes, find the reason,
and identify where their disagreement enters.

## Deliverable group B — symbolic game model

- complete module and interface map;
- typed canonical state;
- action, authority, implementation, observation, and consequence transitions;
- persistent world sampling and named event shocks;
- policy variants and starting state;
- narrative renderer/postmortem contract;
- terminal survival/extinction processes;
- explicit omissions and abstraction ledger;
- future code conformance checklist.

Acceptance test: an expert can inspect the entire simplified model without
sampling runs, and a developer can tell whether code implements it.

## Deliverable group C — elicitation and pruning

- August 2026–July 2027 event/path decomposition;
- conditional rather than context-free forecast questions;
- provenance and uncertainty vocabulary;
- criteria for represent / compress / scenario-only / omit;
- public-discourse-value and policy-ordering tests;
- compact disagreement response form;
- prioritized next human review batch.

Acceptance test: Jörn can correct important beliefs quickly, and the project can
justify why an expensive pathway is or is not in the game.

## Quantification sequence

1. agree on event and conditioning semantics;
2. identify structural families and causal parents;
3. record qualitative direction and order-of-magnitude timescale;
4. elicit broad conditional ranges only where consequential;
5. check coherence constraints and implied marginals;
6. decide which values belong in expert forecasts, game calibration, or only
   adversarial stress cases;
7. separately transform for playability if needed and disclose the transform.

## Stop conditions for autonomous work

Pause for Jörn when one of the following is true:

- a high-level structural choice reverses several policy comparisons;
- the first-year forecast cannot be decomposed further using public evidence;
- two plausible expert models require different canonical game objects;
- pruning a pathway risks deleting the main reason for a treaty provision;
- a positive safe-ASI route requires substantive alignment ontology rather than
  standard assurance structure; or
- the artifact group is coherent enough that additional autonomous detail has
  lower value than expert error-finding.
