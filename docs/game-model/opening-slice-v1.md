# Executable opening slice v1

Status: playable internal opening slice; structurally tested; uncalibrated; not
release-ready.

## Boundary

This slice exists to test the architecture before authored content scales. It
contains:

- the US and PRC as founding signatories;
- one declared frontier site in each country and one diagnostic covert site;
- the cold, restricted and broad inference policies;
- separate declared and implemented inference policy fields;
- legal prohibition, deterrence, factual credential control, telemetry,
  analysis, reporting, local stop and central-enforcement latency;
- training-resource coverage using compute, accelerator memory and topology;
- hosted inference request, declared/true purpose, classification,
  authorization, execution and artifact stages;
- capability artifact creation as nonterminal technical state;
- dangerous-run start and internal RSI as separate timestamped transitions;
  takeover currently produces the terminal extinction state in the same
  transition; and
- hidden truth, information objects, DG-visible events and retrospective trace
  material.

It deliberately excludes complete political operation, public opinion, treaty
accession, consolidation rollout, safety exit, macroeconomics, detailed
research, authored progression, and a calibrated game distribution.

## Timestamped control race

```text
actor considers violation
   ├─ ordinary + credible apprehension/sanction → abandons
   └─ proceeds
       ├─ factual credentials deny startup → blocked
       └─ workload starts
           ├─ no telemetry / missed signal → no report
           └─ signal → analysis → report may or may not reach DG

scheduled independently:
  local/central stop ─┐
  workload completion ├─ earliest applicable event changes reachable paths
  internal RSI        ┤
  takeover completion ┘
```

Starting a run is not terminal. Crossing the hidden internal RSI boundary is
represented separately from takeover. In the present slice, takeover and the
terminal extinction state occur in the same transition. An interruption before
the RSI boundary cancels later route events but does not disclose the cancelled
deadline to the player.

## Resource coverage

`PAUSE-LIMITS-2026-V1` is encoded as the exact scenario fixture already used in
the review cards:

- prohibited training above `1e24` FLOP;
- prohibited post-training above `1e23` FLOP; and
- covered cluster when topology is connected above the fixture's bandwidth
  trigger and either H100-equivalent count or accelerator-memory threshold is
  exceeded.

The limits are not endorsed safe thresholds. A compute-only diagnostic variant
demonstrates the route that memory coverage closes. Coordinated resource parts
aggregate before workload classification. The kernel does not yet model the
continuous slowdown/feasibility curve for dispersed training.

## Inference path

The diagnostic supports ordinary service, disguised capability research and an
open-weight residual capability session. Classification can be correct,
ambiguous or a false negative:

- cold denies hosted non-integrity work;
- restricted stops classified capability work and ambiguity, but can admit a
  registered disguised session after a false negative;
- broad permits it;
- already released open weights remain usable outside the hosted policy;
- completion may produce a specific communicable efficiency artifact in a
  latent diagnostic world; and
- the artifact changes technical opportunity but is not a loss condition.

This is an architecture fixture. The balanced hidden branches in the diagnostic
world are deliberately **not** Jörn's 25%/10% judgment. Before calibration the
engine still needs task-specific artifact applicability, larger session
portfolios and evidence-based policy implementation processes.

## Passing tests

The current suite verifies:

- stable named draws independent of call order;
- timestamp rather than insertion-order race resolution;
- same-time structural ordering;
- opening declared-site control premises;
- legal prohibition does not directly set conduct;
- credible punishment can deter an ordinary diagnostic actor;
- a catastrophic gambler can proceed to the factual-control check;
- intact multiparty credentials can block that residual actor;
- a local monitor can interrupt a run without revealing hidden closeness;
- a true report can fail to reach the DG;
- a false alert can occur with no violation;
- paired inference policies preserve the unrelated sensor draw;
- cold/restricted versus broad authorization behavior;
- memory as an alternative coverage trigger;
- compute-only coverage missing a memory-heavy pool;
- coordinated-resource aggregation;
- fixture and hidden-world values remain labeled diagnostic; and
- every terminal diagnostic trace contains an internal RSI boundary before
  takeover.

Run with `npm test`. Run a paired diagnostic with `npm run diagnostic -- SEED`.

## Architecture decisions now protected

1. Truth, evidence, actor receipt and player display are different objects.
2. Timestamped events, not cards or turns, resolve technical/control races.
3. Random draws use stable causal keys.
4. Cards emit typed actions, but the current reducer still maps some choices
   directly into fixture truth; institutional mediation is an expansion gate.
5. Legal text, implementation and factual control stay separate.
6. Hardware, weights, inference sessions and parameter-changing workloads stay
   separate.
7. Structural rules and calibration fixtures have different provenance.
8. Breaches and capability artifacts remain nonterminal until a complete unsafe
   control-loss path resolves.
