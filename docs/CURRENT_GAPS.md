# Current development gaps

This is the durable backlog for boundaries that should be addressed before the
opening diagnostic becomes a larger authored game. It records known gaps, not a
fixed implementation order or approved product design.

## Game and model boundary

- Player choices currently configure diagnostic fixture truth directly. Route
  decisions through jurisdiction-specific authority and implementation before
  scaling content.
- The dossier exposes too little causal feedback: materially different choices
  can produce the same player-visible result. Add known implementation receipts
  and a clearly separate retrospective/counterfactual surface.
- The loop is a fixed assay rather than progressing play. Safe terminal paths,
  longer institutional operation, and authored progression are absent.
- Takeover currently produces extinction in the same transition. Custody,
  access, reinvestment, interruption, and manifestation need explicit boundaries
  before expanding this route.
- Artifact effects use a global multiplier. Represent target-specific transfer,
  applicability, evaluation, implementation, and fizzle before calibration.
- Engine state time can precede the final trace timestamp. Persistence and
  save/load schemas are not implemented.

## Player experience and validation

- The dominant mobile card disables native touch scrolling and swipe handling
  lacks axis discrimination.
- Device profiles run Chromium only. Safari/WebKit, real touch input, and actual
  devices remain untested.
- Focus, reset, empty-dossier layout, and causal-result legibility need review.
- The current preview is an internal structural prototype, not evidence of fun,
  comprehension, calibration, or target-user usability.

## Domain and evidence

- The expert atlas is synthesis, not a complete claim-level source map. Claim
  cards need sentence-level provenance and approval status.
- First-year likelihood language must not outrun the unresolved forecast
  register.
- `model.yaml` includes intended political and safety ontology that is not yet
  executable; do not describe specification coverage as implemented behavior.
- Restored literature is a research aid. Verify original sources and construct
  claim-level mappings before promoting it into expert or player-facing claims.
- High-value Jörn context in raw excerpts remains to be promoted as attributed
  draft material and reviewed.

## Operations

- CI is advisory because `main` is not branch-protected.
- Cloudflare preview access and routing must be verified from current external
  state before each deployment; follow `.agents/skills/deploy/SKILL.md`.
